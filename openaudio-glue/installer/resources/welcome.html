OpenAudio Glue @VERSION@ — @EDITION@ edition

For the FireWire 1814 only. Glue adds an input device for each FireWire 1814 ("FireWire 1814 Glue") that carries the unit's inputs through an analog-style chain (transformer, tube, EQ, compressor, desk, tape), and the OpenAudio Glue app to set it.

Needs: @REQ@, and the OpenAudio BeBoB MAFW package 0.6.0 or later (driver 0.4.0, with the Glue tap) installed first, with the Mac restarted after it. The installer stops if the driver is missing.

During the install Core Audio restarts: any audio playing stops for a moment.

The colour stages are ports of Airwindows plug-ins by Chris Johnson (MIT); the notice is in the app's Resources (NOTICE.md).

Homebrew software for owners of M-Audio FireWire hardware; M-Audio's products and names belong to their owners.
