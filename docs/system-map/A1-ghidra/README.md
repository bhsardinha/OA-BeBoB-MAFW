## How to resume

1. Pick the next unblocked `Qn` from the table.
2. `grep -n '^__ZN<mangle>' docs/system-map/A1-ghidra/otool-exports/mafw.asm` to find the symbol's line; `sed -n 'N,Mp'` to pull the body.
3. Decode registers against System V AMD64 ABI (rdi/rsi/rdx/rcx/r8/r9/stack).
4. Compare against the clone's corresponding `.cpp`/`.h` under `openaudio-fw1814/kext/`.
5. Write `Qn-<topic>.md` with: pseudocode, clone comparison, delta table, provenance.
6. Add follow-ups to this index. Update auto-memory only after a finding supersedes a prior memory.
