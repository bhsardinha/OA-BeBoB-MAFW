## Observations (cited)
1. **Class chain:** `IOAudioEngine → FWTimeSlaveEngine → FWPairEngine` (separate from `FWDiscreteEngine → FWBaseEngine → FWEngine2`). `FWPairStream` is an `IOAudioStream` whose only override is `mixOutputSamples @0x1b59e` = `audioEngine->vt[0xac0]` (delegates mixing to the engine). `FWEngine1` has no methods in this binary (its name only appears as the unique-ID class string for `[+0x34a]` engines of other products). Pair engines are **optional**: created only when the property `MAEnableStereoPairEngines` is non-zero (SL default 0, Q-P4).
2. **FWTimeSlaveEngine:** `SetMasterEngine @0x19e8a`: master `[+0x118]`, master's status descriptor `[+0x120]` (`GetStatusDescriptor`, retained), `[+0xb0]` (`status`) := its bytes, the engine's `reserved->statusDescriptor` replaced by it, `setNumSampleFramesPerBuffer(master [+0x88])`. `getCurrentSampleFrame @0x19e06`, `performAudioEngineStart/Stop @0x19dd6/@0x19dee` forward to the master; `free @0x19d8c` clears `status`.
3. **FWPairEngine fields:** `[+0x12c]` engine bit index, `[+0x130]` / `[+0x134]` first output / input channel of the pair in the multichannel buffers, `[+0x138]` output stream, `[+0x140]` input stream, `[+0x148]` `TRingBuffer`, `[+0x178]` ring bytes = `numSampleFrames * 8`, `[+0x17c]` has-input, `[+0x17d]` has-output.
4. **initHardware @0x1aff8:** `IOAudioEngine::initHardware`, `setSampleRate(44100)`, `setNumSampleFramesPerBuffer(master)`, ring, then an output `FWPairStream` (direction 0, start channel 1; format = the 24-byte constant at `0x2fc80` = 2 ch, `'lpcm'`, `'sint'`, 24-in-32, high-byte, big-endian, mixable, tag 0) whose **sample buffer is the private ring** and whose **mix buffer is the master's multichannel mix buffer**; an input stream the same way; `vt[0xbf8]` = `ResetIOFormat(&master.sampleRate)`; `setRunEraseHead(false)`.
5. **Sample path:** `mixOutputSamples @0x1af32` adds the pair's two float channels into `masterMix + first*channels` at channel offset `[+0x130]` (`_MixChannelPairToMultichannelBuffer`: dst[stride·f + off] += src[2f]; dst[stride·f + off + 1] += src[2f+1]); `clipOutputSamples @0x1af04` = `master.ClipSubEngineOutput(1<<idx, …)`; `convertInputSamples @0x1ae64` = `master.ConvertSubEngineInput(1<<idx, …)` then `_CopyChannelPairFromMultichannelBuffer` of channels `[+0x134]`,`+1` from the master's converted float buffer into the client buffer.
6. **Activation:** `performAudioEngineStart/Stop @0x1ae44/@0x1ae22` = `master.ActivateSubEngine/DeactivateSubEngine(1 << idx)` (M-D code); `stopEngineAtPosition @0x1ace6` = (empty master call) + `stopAudioEngine`; `setState @0x1ad40` writes `state` and the `IOAudioEngineState` property only; `performFormatChange @0x1ad32` returns 0; `resetStatusBuffer` empty.
7. **ResetIOFormat @0x1ab42:** begin config change; for the input and/or output stream: clear available formats, add the 24-byte format for `rate`..`rate`, `setFormat`; `setSampleRate`, `hardwareSampleRateChanged`; copies the master's `IOAudioEngineInputSampleLatency`, `…OutputSampleLatency`, `IOAudioEngineSampleOffset` properties; complete. `FWDiscreteEngine::ResetStereoPairIOFormats @0x18a2a` calls it on every pair (pending bit `0x400000`).
8. **CreateStereoPairSubEngines @0x30f2:** walks the `DeviceChannels` group list (terminator type 3 — the table has a fifth entry, Q-ME §7b); per group a pair counter `idx` restarts at 1; a pair engine is looked up by `(signal type, idx)` (`FWTTrio` = {type, idx, engine}), created when missing (`init`, `SetMasterEngine(main)`, `[+0x12c] = bitIndex`, `master.AddSubEngine`); the direction flag and channel offset (`firstPair*2-2`, +2 per pair) are set for every visit; `bitIndex` increments for **every** pair visited. `NameAndActivatePairEngines`: description `"<GetDescriptionString> <Analog|S/PDIF|ADAT> <2n-1>/<2n>"` + `" In"` when only an input / `" Out"` when only an output exists, then `activateAudioEngine`. Type strings at `0x2da8f / 0x2da96 / 0x2da9d`. `RemoveAllSubEngines @0x189a6` = `terminate(0)` on each, empty the set.
9. **Device property:** `SetExportStereoPairEngines @0x1dd6`: with a main engine, value 0 → `RemoveAllSubEngines`, else `CreateStereoPairSubEngines` (vt `0xa40`); `SwitchDigitalSignals` rebuilds them after a digital-format change when the property is on (value cell `[+0x184]`).

## Clone mapping
`FWTimeSlaveEngine.{h,cpp}`, `FWPairEngine.{h,cpp}` (+ `FWPairStream`), `FWDiscreteEngine` sub-engine set (now an `OSSet`), `FWAudioDevice::{SetExportStereoPairEngines, CreateStereoPairSubEngines}`; the `FWTTrio` objects are a local array (max 16). Pair engines are registered normally (only the main engine defers `registerService`).
